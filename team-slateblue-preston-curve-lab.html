label_codes <- countries %>%
  filter(
    gdp_per_cap >= nth(sort(gdp_per_cap, decreasing = TRUE), 10) |

4.7 Reason choice of Log Axis Ticks

# Create a colour for each region
region_colours <- scales::hue_pal()(length(unique(countries$region)))
names(region_colours) <- unique(countries$region)

plot(
  x = countries$gdp_per_cap,
  y = countries$life_exp,
  log = "x",
  pch = 16,
  cex = scales::rescale(sqrt(countries$pop), to = c(0.5, 4)),
  col = scales::alpha(region_colours[countries$region], 0.6),
  xlab = "GDP per Capita (PPP, log scale)",
  ylab = "Life Expectancy (years)",
  main = "Gapminder-style Bubble Chart (2024)"
)

text(
  x = countries$gdp_per_cap,
  y = countries$life_exp,
  labels = countries$label,
  pos = 4,
  cex = 0.7
)

legend(
  "bottomright",
  legend = names(region_colours),
  col = region_colours,
  pch = 16,
  bty = "n"
)
  • One other advantage of ggplot2 approach: It shows equal ratios for the same equal visual distances, such as from 1000 to 3000, and for 10,000 to 30,000. GDP per capita typically varies by orders of magnitude across countries, hence ratio comparisons will be more meaningful than absolute differences.
  • For a gapminder chart, Gapminder’s doubling scheme places each tick at twice the previous value, such as from 1000 to 2000 and for 10,000 to 20,000, so equal distances along the axis represent the same multiplicative factor, making it easy to see how many times richer one country is than another.

  1. In your opinion, should the color or size legend appear at the top? Why? No, if the legend is on top/below of the graph, it will be hard for the user to reference the legend visually as they will have to scroll up/down to reference the legend especially if the graphs is bigger.

  2. Does reversing the size legend make the population mapping easier to read? Why? Yes, showing the larger area bubble on the legend showing larger population will help as they are more visually dominant and reduces the cognitive load as there will not be a need for mental reversal to match the bubble on plot to the legend from small to large.

  3. Why should the color legend use opaque symbols (alpha = 1) although the plotted points are semi-transparent? To allow the readers to easily identify which color maps to which region quickly, as the semi-transparent serves a different purpose when used to describe the data on the plot.

From the Preston Curve, we are able to derive that life expectancy rises steeply with GDP per capita at low income levels but flattens considerably beyond roughly $30,000–$75,000 PPP, and falls after. One surprising factor would be how life expectancy in the US falling below the LOESS trend line, which would be different from what we expect from a high income country as comapred to the East Asian or European Nations. This can also be referenced from an article by The Peterson-KFF Health System Tracker, which is a reputable, well-regarded publication, a collaboration between the Peterson Center on Healthcare and the Kaiser Family Foundation. According to the Peterson-KFF Health System Tracker, the United States spends far more on healthcare per capita than any comparable wealthy nation yet achieves a lower life expectancy than most of them which is a pattern clearly visible as an outlier below the LOESS trend line in the plot that was produced.

4.7 Reason choice of Log Axis Ticks
```{r}
# Create a colour for each region

names(region_colours) <- unique(countries$region)

  x = countries$gdp_per_cap,
  y = countries$life_exp,
  log = "x",
  pch = 16,
  cex = scales::rescale(sqrt(countries$pop), to = c(0.5, 4)),
  col = scales::alpha(region_colours[countries$region], 0.6),
  xlab = "GDP per Capita (PPP, log scale)",
  ylab = "Life Expectancy (years)",
  main = "Gapminder-style Bubble Chart (2024)"
)

text(
  x = countries$gdp_per_cap,
  y = countries$life_exp,
  labels = countries$label,
  pos = 4,
  cex = 0.7
)

legend(
  "bottomright",
  legend = names(region_colours),
  col = region_colours,
  pch = 16,
  bty = "n"
)
```
- One other advantage of ggplot2 approach: It shows equal ratios for the same equal visual distances, such as from 1000 to 3000, and for 10,000 to 30,000. GDP per capita typically varies by orders of magnitude across countries, hence ratio comparisons will be more meaningful than absolute differences.
- For a gapminder chart, Gapminder's doubling scheme places each tick at twice the previous value, such as from 1000 to 2000 and for 10,000 to 20,000, so equal distances along the axis represent the same multiplicative factor, making it easy to see how many times richer one country is than another.

a. In your opinion, should the color or size legend appear at the top? Why?
No, if the legend is on top/below of the graph, it will be hard for the user to reference the legend visually as they will have to scroll up/down to reference the legend especially if the graphs is bigger.

b. Does reversing the size legend make the population mapping easier to read? Why?
Yes, showing the larger area bubble on the legend showing larger population will help as they are more visually dominant and reduces the cognitive load as there will not be a need for mental reversal to match the bubble on plot to the legend from small to large.

c. Why should the color legend use opaque symbols (alpha = 1) although the plotted points are semi-transparent?
To allow the readers to easily identify which color maps to which region quickly, as the semi-transparent serves a different purpose when used to describe the data on the plot.
